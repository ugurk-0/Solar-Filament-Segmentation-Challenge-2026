# PQ 0.60 research target — 29 September 2026

**0.60 is a target, not a measured result.** Unless clarified otherwise, the
target refers to Kaggle PQ. Local research estimates and leaderboard scores are
recorded separately. The latest retained checkpoint/configuration measures
mean image PQ **0.271428** and pooled PQ **0.271003** on 85 reused assessment
observations. Its new leaderboard score is unknown; the older 0.24 result was
reported by the project author.

## Diagnosis

The corrected baseline has SQ 0.642751, RQ 0.421630, TP 269, FP 359, and FN 379.
At unchanged SQ, PQ 0.60 would require RQ about 0.9335. This calls for a large
improvement in finding and separating instances, not just a different CSV
encoding or a small threshold change.

The existing false-positive analysis shows nearly overlapping predicted
confidence distributions for correct and incorrect detections. Two earlier
three-epoch fine-tuning trials did not produce an accepted assessment gain.

`python audit_annotation_agreement.py` sampled 24 duplicate-annotation groups
from fold-1 training observations, using seed 2026 and the first two annotation
sets in each sampled group. Mean pairwise instance PQ was **0.313363**; median
was **0.338358**. This is a small descriptive sample of annotation agreement,
**not a bound on achievable model PQ**. It motivates testing the treatment of
conflicting training labels.

## Completed inference-context experiment

Hypothesis: matching inference context to the 768-pixel training crop might help
the GroupNorm model. `python experiment_window_context.py` compared window/overlap
pairs 1024/256, 768/256, and 512/128, with thresholds 0.65/0.80/0.90 and minimum
areas 200/500. Checkpoint, support, physical split, and no-TTA settings stayed fixed.

Calibration on 40 observations selected the original 1024/256, 0.80, 500 setting.
The frozen setting reproduced the baseline on the 85-observation assessment.
**No improvement; no replacement candidate was promoted.**
See [full results](window_context_20260929.md).

## Training experiment

`experiment_annotation_medoid.py` selects one existing annotation set per
training observation, maximizing mean pairwise instance PQ within its annotator
group. Ties use image-ID order. It never selects among validation labels and
does not manufacture new masks. It changes both target selection and duplicate
observation weighting; it is not an isolated loss ablation. Two-annotator groups
always tie, so selection cannot establish which annotator is correct.

The planned run warm-starts the same Round-5 EMA checkpoint for six epochs,
monitors the same 16 observations, and freezes the original post-processing.
The selected checkpoint is assessed on the existing 85-observation research
subset. Promotion requires improved pooled PQ and a positive lower paired
bootstrap bound. Reuse of this subset still introduces selection bias; a gain
would require further confirmation before a leaderboard claim.

```powershell
python -m pytest tests/test_annotation_medoid.py -q
python experiment_annotation_medoid.py --smoke
python experiment_annotation_medoid.py
```

Run state, checkpoints, and provenance are isolated under
`runs/annotation_medoid_20260929/`. The full run writes
`reports/annotation_medoid_20260929.md` at each epoch and after assessment.
The prior submission is preserved.

## Longer-term evidence

A separate [published two-stage solution](https://github.com/HeShen-1/filament-segmentation-2026)
reports 0.3593 five-fold mean PQ and a 0.35 leaderboard result. These are that
author's measurements, not independently reproduced here. They support
investigating detection plus instance refinement, but do not establish that
0.60 is attainable. Older notebook titles advertising around 0.70 predate the
competition's metric change and cannot be treated as current PQ evidence.

No external checkpoint, public test annotation, or test-set parameter tuning
is used by the experiments in this report.
